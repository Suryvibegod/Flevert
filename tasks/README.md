# tasks/

Working notes for the maintainers, written in Vietnamese as the project's convention says (code, UI, commits and the README are in English).

- [HANDOFF.md](HANDOFF.md): the current state, decisions and the next task. Start here.
- `plan.md`, `todo.md` and one folder per module (`image/`, `installer/`, `perf/`, `release/`): the plan, task list and review log of each piece of work. They are a history: they keep old names and commit ids as they were when written.

Contributors do not need these files. The specification of each module is in [docs/specs](../docs/specs), decisions are in [docs/adr](../docs/adr), and how to contribute is in [CONTRIBUTING.md](../CONTRIBUTING.md).
