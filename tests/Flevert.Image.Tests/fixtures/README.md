# Test fixtures

| File | Origin |
|---|---|
| `gradient-320x240.heic` | Generated for this project by `make_heic_fixture.py` (pillow-heif 1.8.1, libheif 1.23.6, x265). A synthetic 320×240 gradient with a white block at the top-left; no third-party image content. Released under the repository's MIT license. |
| `portrait-gps.heic` | Generated by `make_portrait_gps_heic.py` (pillow-heif 1.8.0, libheif 1.23.4, x265): a phone-style portrait shot stored 320×240 with both a HEIF rotation (irot) and EXIF Orientation 6, the rotation layout iPhones use, plus GPS coordinates of a public landmark and made-up camera make/model strings. Real iPhone files are also tiled (grid) images with a gain map; that part is not covered. Upright it is 240×320 with a white block at the top-left. Synthetic. MIT. |
| `blended-240x180.webp` | Generated for this project by `make_blended_webp_fixture.py` (Pillow 12.3, libwebp): a 6-frame lossless animated WebP whose frames cover the canvas and are alpha-blended (transparent = keep the previous frame), as gif2webp makes them. Synthetic noise content. MIT. |
| `mixed-g4-colour.tif` | Generated by `make_tiff_fixtures.py` (Pillow 12.3): page 1 a black-and-white Group 4 text page, page 2 a colour LZW page, as scanners with automatic colour detection write them. Synthetic. MIT. |
| `with-thumbnail.tif`, `thumbnail-first.tif`, `pages-with-thumbnails.tif` | Generated by `make_tiff_fixtures.py`: a 300×200 LZW image with a 75×50 reduced-resolution thumbnail (NewSubfileType = 1) after it, before it, and two pages each followed by a thumbnail. Synthetic. MIT. |
| `wide-50000x1.png` | A solid grey 50000×1 PNG (356 bytes) written by Magick.NET without resource limits, to prove the width limit. MIT. |

Regenerate with (`python -m pip install pillow pillow-heif`):

```
python make_heic_fixture.py gradient-320x240.heic
python make_portrait_gps_heic.py portrait-gps.heic
python make_blended_webp_fixture.py blended-240x180.webp
python make_tiff_fixtures.py .
```

Every other test image is generated at run time by the tests themselves.
