# ConvertAnything

Right-click any image, video, audio or PDF file in Windows Explorer to convert or compress it in place. Everything runs offline on your machine; the result is saved next to the original file.

> Status: early development. Nothing is usable yet.

## Build

Requires the [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0).

```
dotnet build ConvertAnything.sln
dotnet test ConvertAnything.sln
```
